Stop reading a function handed to a call that runs it at once or schedules it as the body of the const, `<default>` or class field that holds the call. A call named `setTimeout`, `setInterval`, `setImmediate`, `queueMicrotask`, `subscribe`, `effect`, `reaction`, `autorun`, `watch` or `$transaction`, a method named `then`, `catch`, `finally`, `map`, `flatMap`, `filter`, `find`, `some`, `every`, `forEach`, `reduce` or `transaction`, or an `on`, `once`, `addListener` or `addEventListener` handed an event and a listener is passed over, its callee read through parentheses, `as`, `satisfies` and `!`: its callback is walked with the call, so on a field it stays on the class whose construction runs or schedules it, and a field such as `timer = setInterval(() => { … })` or `off = emitter.on("x", () => { … })` is no longer a member Symbol, so callers of `new C()` keep the callback's effects and a call of the disposer no longer takes them. A class of such fields is still not a data model. Other calls, wrappers such as `withAuth(() => { … })`, lodash's `once(fn)` and a point-free `map(fn)` among them, are read as before.
